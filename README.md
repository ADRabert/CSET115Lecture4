# CSET 115 Lecture 4: Data Structures in JS

## Lecture Info
This lecture goes over several different data structures & objects in JavaScript that can be used to organize values in various ways.

## Exercises
1. Create a function that removes all even numbers from an array
2. Create a function that removes all duplicate values from an array using the Set object
3. Create a function that checks for a specific value in an array
4. Create a function that gets the ASCII character of a value, then pairs each character with their respective value in another array
